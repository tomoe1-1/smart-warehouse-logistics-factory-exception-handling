仓储异常调度软件层（可直接运行）
==============================

这是挂在已有 WMS / MES 上的异常调度软件层。别人拿到后不必安装 Node.js，也不用再配置开发环境。

使用方法
--------
1. 把整个「仓储异常调度软件层-可运行版」文件夹拷到 Windows 电脑上（不要只拷里面的某一个文件）。
2. 双击「仓储异常调度.exe」。
3. 软件会自动打开浏览器，地址是 http://127.0.0.1:4721
4. 用完后关闭那个标题为「仓储异常调度软件层」的窗口，软件就会退出。

如果双击 exe 被系统拦截，可以改用同目录的「启动.bat」（单机模式，绑定 127.0.0.1）。
如果需要现场多台电脑/车间平板协同，或接收局域网另一台 WMS/MES 服务器的推送，请双击「启动-局域网联调版.bat」（开放 0.0.0.0:4721 并自动打印本机局域网地址）。

说明与多终端协同
----------------
- 工单状态机、追踪进度与组织技能已支持服务端实时落盘共享（data\app-state.json），控制室电脑与车间巡检平板访问同一地址即可实时看到最新在途进度。
- 页头的「备份与报告」可随时导出运行备份（.json，用于换电脑或交接班导入恢复），并可一键导出试点明细表（.csv，Excel 可直接打开）与试点汇报文档（.md）。
- 页头的「重置演示」可回到预置样本（不会清空你在「现场配置」和「现场对话」中保存的连接参数、设备及人员名册，并可勾选同步清空未接入的外部推送队列）。
- 本机 4721 端口需要空闲。若该端口已被占用，软件会提示或打开已有页面。
- 运行过程中如启动失败，可查看同目录下的 runtime.log。

现场配置与技术契约
----------------
打开软件后，点页头的「现场配置」。现场实施或集成商在这里填表即可，不用改代码，也不用安装开发环境。

- 为 WMS、MES、现场信号选择对接方式：先用演示数据、接口对接、对方推送（支持同时开启 HTTP 或数据库回写），或中间表（已内置 SQL Server 与 MySQL 直连读写驱动，免装数据库客户端）。
- 若客户现成 WMS/MES 字段名不同（如 billNo、locCode、errType），直接展开「异构字段映射」填写映射名即可，不用改客户代码。
- 可在「现场配置」顶部开启每 10~60 秒后台自动拉取新异常（自动进入「01 发现」，关键决策仍由人工确认）。
- 切换为接口对接、对方推送或中间表时，可直接展开「查看对接规范 / 建表 DDL」，一键复制或下载 SQL Server / MySQL 建表脚本、Webhook curl 示例与 HTTP 接口契约发给对方 IT 或 DBA。
- 填好地址、账号或表名后，先点「测试这个连接」，再保存（已保存的密码与令牌自动脱敏保护）。
- 现场增加或撤掉设备（含料箱库巷道配置），也在同一页添加、停用或删除。
- 配置保存在本文件夹的 data\site-config.json，中间表回写队列留存在 data\table-writeback-outbox.json，拷贝整个软件目录时会一起带走。
- 演示数据仍可继续使用。真正连上现场后，异常会按填写的方式接入与回写；回写被拒时步骤不会往前虚报成功，关键调度仍需人工确认。

现场对话、组织技能与本机模型
------------------------
- 打开页头的「现场对话」，可以用中文说明要改的人员姓名、职责描述、搬运路线，或直接用中文停用/启用设备、修改设备备注说明。软件会先给出草案，点「确认写入」后才生效，不会自动改现场系统。
- 打开页头的「组织技能」，可随时修订或删除已沉淀的技能；同类异常初判时会自动按巷道与现场场景优先推荐匹配技能。
- 本文件夹的 runtime\model 里内置了离线小模型，runtime\llama 里是本机推理程序，启动软件时会在本机加载，不需要联网，也不要删掉这两个目录。
- 在异常闭环的初判步骤，也可以点「请本机模型再看一眼」。模型只写建议，关键调度仍需人工确认。
